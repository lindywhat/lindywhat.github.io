I want to make a static website hosted on Github using Jekyll. It should prioritise ease of updating.

In this repository make a website that as closely as possible mimicks the look and content of https://www.lindynijmegen.org/
If certain dynamic elements are not possible to make in a static way, then it is okay to simplify somewhat.
Again, the priority is that the structure of the pages should be clear and as easy as possible to update by non-technical people.
